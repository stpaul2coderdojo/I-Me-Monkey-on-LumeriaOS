## 🐒 Executive Summary

**I-Me-Monkey DAO** is an institutional-grade, cross-chain decentralized autonomous organization engineered to fund, govern, and verify the permanent rehabilitation of rescued primates (former biomedical research and exotic pet captives) within an expansive arboreal haven across the **Marshall Islands (Majuro Atoll, Laura Sanctuary Zone, and Arno Atoll)**.

The DAO bridges **Ethereum Layer-1** (deep institutional treasury liquidity and governance anchoring) with **Avalanche C-Chain & Subnets** (sub-second finality, micro-donations, and Miyawaki canopy corridor sensor telemetry). It completely removes non-crypto onboarding friction through **Google Wallet Generic Object Pass tokenization**, empowering members to hold verifiable voting rights and soulbound primate guardianship passes directly inside their mobile Google Wallet with zero seed-phrase complexity.

### 1. Cross-Chain Settlement (Ethereum & Avalanche)
- **Ethereum Mainnet**: Anchors long-term capital preservation, Timelock governance controllers, and high-value endowment reserves.
- **Avalanche C-Chain & Custom Primate Haven Subnet**: Handles high-frequency voting, micro-grants, Miyawaki reforestation land parcels, and real-time environmental IoT telemetry.
- **Cross-Chain Bridge Security**: Monitored by Google Antigravity autonomous security agent to prevent state desynchronization, double-voting, or reentrancy vectors.

### 2. Google Wallet Mobile Tokenization
- Eliminates the UX barrier of seed phrases for conservationists, donors, and island stewards.
- Utilizes the **Google Wallet REST API Generic Objects & Classes** schema to issue:
  - **Soulbound Rescued Primate Custody Pass**: Encodes verified primate biometric twin IDs, health milestones, and habitat coordinates.
  - **DAO Voting Power & $IMM Token Pass**: Displays real-time on-chain voting weight, QR codes for governance ratification, and live tier badges.
  - **Cryptographic Verification**: Barcodes signed with Cloud KMS for fast in-person sanctuary validation and local community participation.

### 3. Google Antigravity Autonomous Security Agent
- Evaluates submitted DAO proposals against cross-chain safety criteria, treasury reserves, and environmental impact thresholds.
- Simulates multi-sig transaction calls prior to on-chain broadcasting.
- Employs Gemini 3.8 Flash model cascade with strict execution timeouts to ensure guaranteed deterministic verdicts.

### 4. LumeriaOS Pixar USD Raytraced Digital Twins & OpenGL Stage
- Generates standards-compliant **Pixar Universal Scene Description (`#usda 1.0`)** stages encoding:
  - **Primate Skeletal Joints & Tail Kinematics**: 8-segment articulated tail chains, spine flexion, and head orientation.
  - **Subsurface Fur & Shading**: Physics-based lighting (`UsdLuxDomeLight`) and tropical ambient occlusion.
  - **Miyawaki Canopy Bio-Corridor**: High-density botanical assets for breadfruit boughs, coconut palms, and lagoon microclimates.
- Features dual-engine rendering: toggle between the **Photorealistic WebGL Simulation** and the **Procedural Pixar USD Stage**.

### 5. Semiotics Lexicon & Ethogram System
- Comprehensive ethological database covering 30+ primate communication modalities (tail kinematics, facial expressions, tactile grooming, acoustic formants).
- Searchable taxonomy categorized by Latin species, communicative intent, social context, and USD layer properties.
- Built-in sound synthesizer reproducing primate vocalization formant acoustics (chirps, coos, alarm barks) and tail flick clicks using Web Audio API.
- **Live Camera Imaging**: Real-time webcam integration with front/rear camera switching, biometric tracking reticles, drag-and-drop file upload, and a simulated **Sanctuary Cam** for remote observation.

## 🚀 Quick Start (Local Development)

### Prerequisites
- **Node.js**: v20.0.0 or higher (Node 22 LTS recommended)
- **npm**: v10.0.0 or higher
- **Gemini API Key** *(Optional for AI autonomous generation)*: Obtain from [Google AI Studio](https://aistudio.google.com).

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/I-Me-Monkey-DAO/DAO.git
cd DAO

# 2. Install dependencies
npm install

# 3. Configure environment variables (optional)
cp .env.example .env
# Edit .env and supply your GEMINI_API_KEY if desired

# 4. Start the local development server (Express + Vite)
npm run dev
```

The application will be live at `http://localhost:3000`.

## 🐳 Docker Deployment

The application includes a production-ready, multi-stage `Dockerfile` with minimal Alpine image footprint, non-root execution, and automatic healthchecks.

### Running with Docker Compose (Recommended)

```bash
# Build and start container in the background
docker compose up -d --build

# View container logs
docker compose logs -f

# Check health status
docker compose ps

# Stop container
docker compose down
```

### Running with Standalone Docker

```bash
# Build Docker image
docker build -t i-me-monkey-dao:latest .

# Run container exposing port 3000
docker run -d \
  --name i-me-monkey-dao \
  -p 3000:3000 \
  -e NODE_ENV=production \
  -e GEMINI_API_KEY="your-gemini-api-key-here" \
  i-me-monkey-dao:latest

# Check container status
docker ps
```

## 🔌 API Reference

The backend Express service exposes secure REST endpoints on port 3000:

### `GET /api/health`
Returns system status, active chains, and timestamp.
```json
{
  "status": "healthy",
  "app": "I-Me-Monkey DAO",
  "chains": ["Ethereum", "Avalanche"],
  "timestamp": "2026-09-17T09:05:06.380Z"
}
```

### `POST /api/wallet/generate-pass`
Generates a signed Google Wallet Pass Generic Object for primate custody or voting rights.
- **Request Body**: `{ "passType": "primate_custody" | "voting_share", "holderName": string, "monkeyName": string, "species": string, "havenLocation": string, "votingPower": number }`
- **Response**: `{ "success": true, "jwt": string, "saveUrl": string, "passObject": object }`

### `POST /api/antigravity/audit-proposal`
Invokes the Google Antigravity autonomous agent to evaluate proposal risk.
- **Request Body**: `{ "title": string, "chain": "Ethereum" | "Avalanche", "budget": string, "description": string }`
- **Response**: `{ "success": true, "riskScore": string, "recommendation": string, "auditSummary": string }`

### `POST /api/antigravity/generate-hd-usd-scene`
Generates a Pixar USDA 1.0 raytraced digital twin scene definition.
- **Request Body**: `{ "atoll": string, "primateName": string, "timeOfDay": string, "environmentMood": string }`
- **Response**: `{ "success": true, "scene": { "id": string, "title": string, "usdaCode": string, ... } }`

### `POST /api/antigravity/generate-bio-usd`
Generates a customized primate rehabilitation biography and Pixar USDA bio schema.
- **Request Body**: `{ "name": string, "species": string, "rescueOrigin": string, "captivityDuration": string, "atoll": string }`
- **Response**: `{ "success": true, "bio": string, "bioDescriptionUsd": string }`
